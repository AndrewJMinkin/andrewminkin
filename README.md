# Andrew J. Minkin — personal site

A minimalist one-page personal website and resume: experience, education, awards, languages, speedcubing personal bests, and contact links.

## Tech

- TanStack Start (React 19) + Vite
- Tailwind CSS 4
- Deployed on Netlify

## Editing content

Everything on the page comes from `src/data/resume.ts`. Update roles, dates, awards, or cube times there and redeploy.

## Run locally

```bash
pnpm install
pnpm dev
```

Or, with Netlify emulation: `netlify dev`.
